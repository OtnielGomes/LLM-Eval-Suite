# Dataset Card — LLM Eval Suite · Curated Q&A

## Overview

A manually curated dataset of question/answer pairs designed to evaluate RAG pipelines
and prompting techniques in the context of **Machine Learning and Artificial Intelligence**.

Thematic coverage is intentional to stress-test the system across factual,
conceptual, and multi-step reasoning questions.

---

| Field       | Value                        |

## Schema

Each line of `curated_qa.jsonl` follows this schema:

```json
{
  "id":           "qa_001",
  "question":     "What is the difference between precision and recall?",
  "ground_truth": "Precision measures the proportion of true positives among all positive predictions, while recall measures the proportion of true positives among all actual positives.",
  "category":     "evaluation_metrics",
  "difficulty":   "basic",
  "source":       "manual"
}
```

### Fields

| Field          | Type   | Description                                               |
|----------------|--------|-----------------------------------------------------------|
| `id`           | string | Unique identifier `qa_NNN`                                |
| `question`     | string | Question in English, objectively formulated               |
| `ground_truth` | string | Expected answer, concise and factually correct            |
| `category`     | string | Thematic category (see below)                             |
| `difficulty`   | string | `basic` \| `intermediate` \| `advanced`                   |
| `source`       | string | Always `manual` — annotated by the dataset author         |

### Categories

| Category               | Description                                        |
|------------------------|----------------------------------------------------|
| `evaluation_metrics`   | BLEU, ROUGE, F1, precision, recall, etc.           |
| `rag_concepts`         | Retrieval, chunking, embeddings, re-ranking        |
| `llm_fundamentals`     | Transformers, attention, fine-tuning, RLHF         |
| `prompt_engineering`   | Few-shot, CoT, zero-shot, system prompts           |
| `benchmarks`           | MMLU, HumanEval, HellaSwag, BIG-Bench              |

## Usage with the RAG Pipeline

This dataset is the primary input for `scripts/evaluate_rag.py`:

```bash
# Evaluate a single strategy with 25 questions
uv run evaluate-rag --strategy naive --limit 25

# Evaluate all strategies
uv run evaluate-rag --limit 25
```

The `ground_truth` field is used by RAGAS to compute `context_recall`.
The `question` field is sent to the RAG pipeline to generate `answer` and `contexts`.

---

## Source Documents (`raw/`)

The files in `raw/` are the texts indexed by the RAG pipeline into ChromaDB.
They must cover the topics in the dataset to ensure fair retrieval evaluation.

| File                      | Content                                          |
|---------------------------|--------------------------------------------------|
| `ml_evaluation.txt`       | ML evaluation metrics (BLEU, ROUGE, F1, etc.)   |
| `rag_overview.txt`        | RAG concepts: chunking, embeddings, re-ranking   |
| `llm_fundamentals.txt`    | Transformers, attention mechanisms, RLHF         |
| `prompt_engineering.txt`  | Prompting techniques: few-shot, CoT, zero-shot   |
| `benchmarks_overview.txt` | Public benchmarks: MMLU, HumanEval, HellaSwag    |

## Curation Process

1. **Topic Selection** — categories aligned with the project scope
2. **Formulation** — unambiguous questions with verifiable, objective answers
3. **Annotation** — `ground_truth` manually written, never generated by an LLM
4. **Validation** — each pair reviewed to ensure factual correctness
5. **Balancing** — even distribution across categories and difficulty levels

> ⚠️ `ground_truth` was never generated by an LLM to avoid evaluation contamination.
