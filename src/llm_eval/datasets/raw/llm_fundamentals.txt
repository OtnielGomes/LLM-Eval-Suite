# LLM Fundamentals

## Transformers and Attention

The Transformer architecture (Vaswani et al., 2017) uses self-attention to process sequences in parallel. Self-attention allows each token to attend to all other tokens in the sequence. For each token, three vectors are computed: Query (Q), Key (K), and Value (V). Attention weights are computed as softmax(QK^T / sqrt(d_k)), then applied to V to produce the output. This mechanism enables the model to capture long-range dependencies without sequential processing.

Multi-head attention runs multiple attention operations in parallel, each learning different relational patterns. The outputs are concatenated and projected. Positional encodings (sinusoidal or learned) are added to token embeddings to encode sequence order.

## Training

Pretraining trains LLMs on large corpora using next-token prediction (causal LM) or masked token prediction (masked LM). This stage requires billions of tokens and thousands of GPU-hours. The resulting model learns general language understanding and world knowledge.

Fine-tuning adapts a pretrained model to a specific task or style by training on a labeled dataset via supervised learning. It updates all or a subset of the model's weights. Full fine-tuning is expensive for large models.

LoRA (Low-Rank Adaptation) fine-tunes LLMs efficiently by adding small trainable rank-decomposition matrices to existing weight matrices, freezing the original weights. Instead of updating all parameters, only the low-rank matrices (typically rank 4–64) are trained, reducing GPU memory by 10–100x. LoRA weights can be merged into the base model at inference with zero added latency.

RLHF (Reinforcement Learning from Human Feedback) aligns LLMs with human preferences in two stages: (1) train a reward model from human pairwise preference data, (2) use PPO or similar RL algorithms to optimize the LLM's policy to maximize the reward model's score. RLHF produced the behavioral shift seen in InstructGPT and ChatGPT compared to base GPT-3.

## Inference

Temperature scales logits before softmax: output = softmax(logits / T). T < 1 produces sharper (more deterministic) distributions; T > 1 produces flatter (more creative/random) distributions. T = 0 is greedy decoding. Top-p (nucleus) sampling restricts sampling to the smallest set of tokens whose cumulative probability exceeds p.

Context window defines the maximum number of tokens the model can process in a single forward pass, including both the prompt and the generated output. Models with longer context windows can process more retrieved chunks in RAG, enabling richer grounding.
