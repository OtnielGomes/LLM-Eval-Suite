# Machine Learning Evaluation Metrics

## Classification Metrics

Precision measures the proportion of true positives among all positive predictions: TP / (TP + FP). A high precision model produces few false positives, meaning when it predicts positive, it is usually correct.

Recall (also called sensitivity or true positive rate) measures the proportion of true positives among all actual positives: TP / (TP + FN). A high recall model misses few actual positives.

The F1 score is the harmonic mean of precision and recall: 2 * (precision * recall) / (precision + recall). It is the preferred metric for imbalanced datasets where accuracy is misleading. The harmonic mean penalizes extreme imbalances between precision and recall more than the arithmetic mean.

Accuracy measures the proportion of correct predictions among all predictions: (TP + TN) / (TP + TN + FP + FN). It is only meaningful when class distributions are balanced.

The ROC-AUC score measures the probability that a classifier ranks a random positive example higher than a random negative example. An AUC of 1.0 is perfect; 0.5 is random.

## Text Generation Metrics

BLEU (Bilingual Evaluation Understudy) computes n-gram precision between a candidate text and one or more reference texts, with a brevity penalty to discourage very short outputs. It was designed for machine translation but is used broadly in NLP. Main limitations: it ignores semantics, is sensitive to tokenization, and correlates poorly with human judgment for open-ended tasks.

ROUGE (Recall-Oriented Understudy for Gisting Evaluation) measures n-gram recall against references. ROUGE-N computes n-gram overlap; ROUGE-L uses the longest common subsequence. It is the standard metric for summarization evaluation. Unlike BLEU, ROUGE is recall-oriented, rewarding coverage of reference content.

Perplexity measures how well a language model predicts held-out text: PP(W) = P(w1,...,wn)^(-1/n). Lower perplexity indicates better next-token prediction. It is not comparable across models with different tokenizers and does not measure factual accuracy or coherence.

## LLM Evaluation

LLM-as-judge uses a large language model to evaluate the quality of another model's outputs. The judge scores dimensions such as faithfulness, relevance, coherence, and helpfulness. Known biases include position bias (preferring the first response in pairwise comparisons), verbosity bias (preferring longer answers), and self-preference bias.

Intrinsic evaluation measures model properties directly, independent of downstream tasks. Examples include perplexity, BLEU, and ROUGE. Extrinsic evaluation measures performance on real downstream tasks such as question answering, summarization, or code generation. Extrinsic evaluation is more meaningful but more expensive to run.
